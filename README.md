This project implements a classical mean–variance portfolio optimization framework using Python. It combines analytical optimization through a KKT closed-form solution with Monte Carlo simulation to explore portfolio opportunity sets. Two scenario models, AI Infra Balanced and Macro Diversified, are constructed using custom return, volatility, and correlation assumptions to reflect distinct market structures. The project evaluates long-only and shorts-allowed portfolio policies, illustrating how risk and return trade-offs expand under short-selling conditions. Sample Average Approximation (SAA) is used to assess the impact of estimation error on the efficient frontier. All results, including portfolio clouds, efficient frontiers, and selected sample portfolios, are exported as reproducible CSV and PNG outputs. This repository is designed to demonstrate both theoretical understanding and practical implementation of modern portfolio theory in an applied quantitative research setting.
